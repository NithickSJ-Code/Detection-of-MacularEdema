1. Data Pipeline and Preprocessing Subsystem

graph LR A[Raw OCT Scans] --> B[Resize 224x224] B --> C[ToTensor] C --> D[Normalize] D --> E[Elastic Deformations] E --> F[Speckle Noise Injection] F --> G[PyTorch DataLoader]

Technical Specifications:

  • Tensor Normalization: Utilized torchvision.transforms.Normalize using ImageNet statistics (Mean: [0.485, 0.456, 0.406], Std: [0.229, 0.224, 0.225]) to center the pixel intensity distribution, accelerating gradient convergence.
  • Biological Augmentations: Engineered custom transformations to simulate hardware variations. Applied elastic deformations using OpenCV grid mappings to replicate natural retinal curvature variations, and injected Gaussian speckle noise to simulate low-SNR (Signal-to-Noise Ratio) scans common in older OCT machines.
  • Memory Management: Implemented a torch.utils.data.DataLoader with num_workers=4 and pin_memory=True to optimize the transfer of tensors from host RAM to GPU VRAM during training batches.

2. DenseNet-121 Feature Extraction & Classification

graph TD A[Normalized Input Tensor] --> B[DenseBlock 1-4] B --> C[Global Average Pooling] C --> D[Modified Linear Classifier] D --> E[Softmax Output 4 Classes]

Technical Specifications:

  • Architecture Selection: Deployed torchvision.models.densenet121. Unlike ResNet which adds features residually, DenseNet concatenates feature maps from preceding layers, preserving low-level edge features (critical for recognizing retinal layer boundaries) throughout the deep network.
  • Transfer Learning: Executed layer-freezing on the initial convolutional layers to preserve pre-trained ImageNet weights. The final classification head (model.classifier) was replaced with a new nn.Linear(1024, 4) layer initialized with Xavier uniform weights to map to the 4 target pathologies (CNV, DME, Drusen, Normal).
  • Optimization: The backward pass utilized the Adam optimizer with a Cross-Entropy Loss function (nn.CrossEntropyLoss) and an adaptive learning rate scheduler to dynamically decay the learning rate upon plateauing validation loss.

3. Weakly Supervised Localization via Grad-CAM

graph LR A[Final Conv Layer] -- Forward Pass --> B[Activations] A -- Backward Pass --> C[Gradients] B --> D[Multiply & Global Average] C --> D D --> E[ReLU Activation] E --> F[Interpolate to 224x224] F --> G[Heatmap Overlay]

Technical Specifications:

  • Hook Registration: Implemented register_forward_hook and register_full_backward_hook targeting features.denseblock4.denselayer16.conv2 to capture feature map activations and corresponding backpropagated gradients during the evaluation phase.
  • Heatmap Generation: Calculated the Global Average Pooling (GAP) of the gradients to obtain neuron importance weights. These weights were matrix-multiplied with the forward activations. A ReLU activation was applied to suppress negative pixels belonging to other classes, isolating the target pathology (e.g., fluid cysts).
  • Spatial Resolution Recovery: Utilized torch.nn.functional.interpolate with mode='bilinear' to upsample the low-resolution 7x7 Grad-CAM heatmap back to the original 224x224 input image space.
  • Algorithmic Bounding Box: Applied a binary threshold to the heatmap array, followed by cv2.findContours and cv2.boundingRect to algorithmically extract the spatial coordinates of the fluid and draw the final localization box.

4. Uncertainty Quantification via Monte Carlo Dropout

graph LR A[Input Tensor] --> B[Forward Pass 1 with Dropout] A --> C[Forward Pass 2 with Dropout] A --> D[Forward Pass N with Dropout] B --> E[Softmax Stack] C --> E D --> E E --> F[Calculate Mean & Variance] F --> G[Uncertainty Score]

Technical Specifications:

  • Stochastic Inference: Standard PyTorch evaluation mode (model.eval()) normally disables dropout layers. We implemented a custom override function to force nn.Dropout layers to remain active (training=True) during the inference phase.
  • Monte Carlo Sampling: For a single given input tensor, the system executes T (e.g., T=20) independent forward passes. Due to the active dropout masks, each pass relies on a slightly different sub-network of neurons, yielding a distribution of softmax probability outputs rather than a single deterministic prediction.
  • Variance Calculation: The system calculates the statistical variance across the T predictions. High variance indicates that the model is highly sensitive to the dropped neurons, generating an actionable 'Uncertainty Score'. This serves as a clinical safety net to automatically flag ambiguous or out-of-distribution (OOD) scans for mandatory human review.

5. Live Camera Inference & OpenCV Subsystem

Technical Specifications:

  • Live Video Capture: Instantiated a threaded cv2.VideoCapture(0) loop to continuously read BGR frames from the hardware camera buffer.
  • Matrix Transformations: Implemented real-time color space conversion (cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)) to match PyTorch's expected tensor format, followed by array slicing to crop the Region of Interest (ROI) defined by the on-screen targeting UI.
  • Inference Threading: Upon interrupt trigger (Spacebar), the cropped NumPy array is converted to a PIL Image, transformed into an un-squeezed tensor (shape: [1, 3, 224, 224]), and passed through the model via input_tensor.requires_grad_(True) to enable Grad-CAM backpropagation in a live environment.
